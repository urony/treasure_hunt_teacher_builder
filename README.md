# חפש את המטמון — בונה משחקים למורים

אתר שבו מורה בונה בלי תכנות משחק "חפש את המטמון" לטלפונים, מפרסם בקישור, ותלמידים משחקים ומפיקים דוח PDF.
האפיון המחייב: `treasure_hunt_teacher_builder_spec_FINAL.md`.

- **צד לקוח:** Vite + Preact + TypeScript (`src/`). תוצרי תלמידים נשמרים רק ב-IndexedDB בטלפון. הדוח (PDF/ZIP) נוצר בדפדפן.
- **צד שרת:** Cloudflare Worker (`worker/index.ts`) + D1 (משחקים) + R2 (תמונות מורה). הוא גם מגיש את קבצי האתר (Static Assets).
- **שיתוף קוד:** `src/shared/` (סכמה, ולידציה, נרמול תשובות) משמש גם את הלקוח וגם את השרת.

## פקודות

```bash
npm install
npm run dev            # Vite בלבד (פרוקסי ל-/api ב-8787)
npm test               # בדיקות יחידה (vitest)
npm run typecheck      # בדיקת טיפוסים ללקוח ולשרת
npm run build          # בונה ל-dist/
```

### הרצה מקומית מלאה (אתר + API + D1 + R2 מדומים)

```bash
npm run build
npm run db:local       # יוצר את טבלאות D1 המקומי (פעם אחת)
npx wrangler dev       # http://localhost:8787
npm run smoke          # בדיקות עשן ל-API מול השרת הרץ
```

> **חשוב — מסלולים ארוכים / OneDrive / שמות בעברית:** על Windows ייתכן ש-`wrangler` מקומי ייכשל עם `internal error` או `SQLITE_CANTOPEN` כשהפרויקט בתיקייה עם נתיב ארוך או עברי.
> זו בעיה של הסביבה המקומית בלבד, לא של הקוד. הפתרון: להפנות את המצב המקומי לנתיב קצר:
> `npx wrangler d1 migrations apply treasure-hunt --local --persist-to C:/th-state` ואז `npx wrangler dev --persist-to C:/th-state`.

## פריסה ל-Cloudflare (לא בוצעה עדיין)

דרוש חשבון Cloudflare. הפרויקט מוכן; הפעולות הבאות הן **שלך** ולא בוצעו:

1. `npx wrangler login`
2. `npx wrangler d1 create treasure-hunt` — העתיקו את ה-`database_id` שהתקבל אל `wrangler.toml` במקום `REPLACE_WITH_D1_DATABASE_ID`.
3. `npx wrangler r2 bucket create treasure-hunt-images`
4. `npm run db:remote` — מריץ את `migrations/0001_init.sql` על D1 בענן.
5. `npm run deploy` — בונה ופורס. הכתובת תהיה `https://treasure-hunt-builder.<חשבון>.workers.dev`; אפשר לחבר דומיין משלכם בלוח הבקרה.
6. **לבדוק מול התיעוד הרשמי של Cloudflare, ביום ההקמה:** מכסות Workers/D1/R2, מגבלות גודל בקשה ותמחור (האפיון מורה לא להסתמך על מספרים ישנים).

### הגדרות סביבה

| משתנה | איפה | משמעות |
|---|---|---|
| `PUBLISH_DISABLED` | `wrangler.toml` → `[vars]` | `"true"` = **מתג חירום**: משבית יצירה/עדכון/העלאת תמונות. משחקים קיימים ממשיכים לעבוד. לשינוי: לערוך ולהריץ `npm run deploy` (או לשנות Variable בלוח הבקרה). |

אין סודות נדרשים. טוקני עריכה נוצרים אקראית ורק ה-hash שלהם נשמר ב-D1.

## מה נבדק ומה לא — מצב נוכחי

ראו `spike-results/RESULTS.md` לטבלה המלאה של בדיקות ההיתכנות. בקצרה:

- נבדק אוטומטית: בדיקות יחידה (נרמול, ולידציה, PDF, ייצוא/ייבוא משחק), בדיקות עשן ל-API, וזרימת המורה והתלמיד בדפדפן שולחן עבודה (Chromium).
- **לא נבדק** (מסומן במפורש): Android Chrome, iPhone Safari, פתיחה מקישור בוואטסאפ, צילום/הקלטה אמיתיים בנייד, שיתוף קבצים בנייד, קריאות ה-PDF העברי בנייד. כדי לבדוק: לפרוס, לפתוח `/spike` בכל מכשיר, ולהריץ את הבדיקות. התוצאות מועתקות מתיבת הטקסט שבתחתית העמוד אל `spike-results/RESULTS.md`.

## קובץ דוגמה לייבוא/ייצוא משחק

`examples/sample-game.json` מראה את המבנה הפנימי (`schemaVersion` + `game`). קובץ "שמור משחק לשימוש חוזר" אמיתי הוא ZIP המכיל `game.json` בדיוק במבנה הזה, ותיקיית `images/`. `examples/sample-game.zip` הוא קובץ שאפשר לפתוח ישירות דרך "פתח משחק ששמרתי".

## החלטות והפרשות מהאפיון שכדאי להכיר

- **דוח תלמיד:** PDF בלבד, ואם יש הקלטות — קובצי קול נפרדים לצד ה-PDF (בלי ZIP). 'שיתוף' שולח את כולם יחד; 'שמירה' מורידה אותם בזה אחר זה. ה-ZIP נשאר רק בקובץ "שמור משחק לשימוש חוזר" של המורה.
- **PDF:** כל עמוד מצויר ב-canvas ומוטמע כתמונה ב-PDF. העברית וה-RTL נכונים תמיד, אבל הטקסט ב-PDF אינו ניתן לסימון או חיפוש. עמודים מיוצרים אחד אחד ו-canvas יחיד נעשה בו שימוש חוזר.
- **Turnstile (אנטי-בוט):** לא הוטמע ב-MVP. ההגנה הנוכחית: הגבלת קצב לפי IP (10 יצירות, 60 עדכונים, 150 העלאות בשעה), מגבלות גודל ותוכן, ומתג חירום. אם יהיה ניצול לרעה — להוסיף Turnstile בפרסום (נקודת הכנסה: `createGame` ב-`worker/index.ts` ו-`onPublish` ב-`src/ui/Editor.tsx`).
- **הגבלות:** עד 25 תחנות, 30 תמונות למשחק, כ-300KB לתמונה (השרת מקבל עד 400KB), עד 3 תמונות תלמיד לתחנה, הקלטה עד 60 שניות.
- **קוד מעבר** נבדק רק בדפדפן ואינו אבטחה. במסלול קווי הוא חוסם מעבר לתחנה הבאה אך לעולם לא חוסם "סיימתי"; במעגלי וחופשי הוא אינו נועל תפריט.
- **מחיקה אוטומטית של משחקים ישנים:** לא מופעלת (דורשת החלטת בעל המוצר).
- **קוד הצד-שרת אינו מריץ סקריפטים מתוכן מורה:** כל הטקסט מוצג כטקסט (Preact מבצע escape), קישורים חיצוניים רק `https:` ונפתחים עם `rel="noopener noreferrer"`, ויש CSP בקובץ `public/_headers`.

## פריסה אוטומטית

Workers Builds מחובר ל-GitHub: כל push ל-`main` בונה (`npm run build`) ופורס (`npx wrangler deploy`) אוטומטית. הרשאת האפליקציה של Cloudflare ב-GitHub צריכה לכלול את המאגר הזה. אם פריסה לא מופיעה בלשונית Deployments, זו הסיבה הסבירה. לפני push מומלץ `npm test` ו-`npm run typecheck`.
